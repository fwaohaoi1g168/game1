# game1

ティラノスクリプトで作ったノベルゲーム。

## 開き方

このリポジトリには、自分で作ったファイルと、手を入れた設定のファイルだけが入っている。ティラノスクリプトの本体と、新しいプロジェクトに最初から入っている見本は入れていない。

1. ティラノスタジオ v6.03 で新しいプロジェクトを作る（画面は 1280×720 のまま）
2. このリポジトリの `data` の中身を、新しいプロジェクトの `data` に上書きでコピーする
3. ティラノスタジオから実行する。タイトルの「はじめから」で遊べる。セーブとロードは右下のメニューから

## フォルダ

- `data/scenario/`：台本（`first.ks` から始まり、`title.ks`、`story.ks` へ進む。`config.ks` は設定の画面）
- `data/system/Config.tjs`：ゲームの設定
- `data/bgimage/`、`data/fgimage/`、`data/image/`：背景、人物、画面の部品
- `data/bgm/`、`data/sound/`：BGM と声
- `data/others/koden/`：セーブ、ロード、メニュー、バックログの画面
