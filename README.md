# game1

ティラノスクリプトで作ったノベルゲーム。


## 外付けの目との関係

このゲームは、全盲の守井清吾が作った、ゲームを自分の手で遊ぶための道具「外付けの目」（https://github.com/shingo-morii/sotozuke-no-me ）を確かめるために、チームのもう1人（守井の妻、みお）が作った。Built with Claude: Japan 2026 の作品の一部。

- 2026年11月2日 12:30 のキックオフのあとに作った（下の「作った時期」）
- 外付けの目に合わせた作りはしていない。普通のノベルゲームとして作った。
- 外付けの目の側（何も知らない Claude Code のセッション）は、遊べる形だけを受け取って、画面と音だけで調べた。ゲームのファイルの中は開いていない

## 遊ぶには（Windows）

Release（https://github.com/fwaohaoi1g168/game1/releases/latest ）の `game1-1.1-win.zip` を落として展開し、`game1\tyranoproject.exe` を起動する。2026-11-08 に作った版（v1.1）で、11/7 に足した、ショップの客のビフォー・アフターの立ち絵と、髪のモアレを直した立ち絵が入っている。作りは ティラノスクリプト v6.03。

外付けの目の取り込みに使ったのは、2026-11-06 に書き出した版（Release `v1.0` の `game1-win.zip`）。

## ライセンス

- コード（`data/scenario/` の `.ks` のうち、タグと仕組みの部分、`data/system/Config.tjs`、`data/others/koden/` の HTML と CSS）：MIT ライセンス（`LICENSE`）
- 絵、音楽、声、台本の文、画面の部品の画像（`data/image/`、`data/bgm/`、`data/sound/`、`data/others/koden/image/` と、台本の文（台詞と地の文））：再利用できない。このゲームを遊ぶこと、紹介のために画面や音を見せることはよい

## 開き方

このリポジトリには、自分で作ったファイルと、手を入れた設定のファイルだけが入っている。ティラノスクリプトの本体と、新しいプロジェクトに最初から入っている見本は入れていない。

1. ティラノスタジオ v6.03 で新しいプロジェクトを作る（画面は 1280×720 のまま）
2. このリポジトリの `data` の中身を、新しいプロジェクトの `data` に上書きでコピーする
3. ティラノスタジオから実行する。タイトルの「はじめから」で遊べる。セーブとロードは右下のメニューから

## フォルダ

- `data/scenario/`：台本（`first.ks` から始まり、`title.ks`、`story.ks` へ進む。`config.ks` は設定の画面）
- `data/system/Config.tjs`：ゲームの設定
- `data/bgimage/`、`data/fgimage/`、`data/image/`：背景、人物、画面の部品
- `data/bgm/`、`data/sound/`：BGM と声
- `data/others/koden/`：セーブ、ロード、メニュー、バックログの画面

### 使った生成 AI の道具とプラン

- 絵：OpenAI の画像生成（Codex に入っているもの）。作者の ChatGPT Plus（有料）のアカウントで使った
- 絵の直し（客とタクミの髪）：Google Antigravity（CLI）の画像生成。作者の Google AI Pro（有料）で使った
- 声：Gemini TTS（Google）。Google Cloud の Vertex AI（使った分を払う有料）で作った。1本（タクミの台詞1つ）だけ Google AI Studio で作った
- BGM：Gemini アプリ（Google。音楽は Lyria）。作者の Google AI Pro（有料）で作った

どの道具の規約も、作った物は使う人のもので、公開を禁じていない（2026-11-07 に OpenAI の利用規約、Google 利用規約、Google Cloud のサービス固有の規約、Gemini API 追加利用規約の本文で確かめた。Google Antigravity の追加規約は、作った物について別の決まりを置かず、Google 利用規約に従う形になっている）。AI で作った物を人が作った物とは見せない（どの規約にもある決まり）。
